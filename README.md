# Yandex Books downloader
## Инструкция по установке среды запуска скрипта (для Windows):
1. Предлагаю к использованию UV — сверхбыстрый менеджер Python от компании Astral.  
Установка из PowerShell: *powershell -c "irm https://astral.sh/uv/install.ps1 | iex"*
2. Установите стабильную версию Python:  
*uv python install 3.14*
3. Сделайте её версией по умолчанию для всех проектов:  
*uv python pin 3.14*
4. Перейдите в папку, в которую будет склонирован репозиторий скрипта.
Склонируйте репозиторий с гитхаба и перейдите в его папку:  
*git clone https://github.com/Rennats/YaBooks_downloader.git  
cd YaBooks_downloader*
5. Создайте виртуальное окружение с помощью UV:  
*uv venv*
6. Активируйте окружение в Windows:  
В PowerShell: *.venv\Scripts\Activate.ps1*  
В CMD: *.venv\Scripts\activate.bat*
7. Установите библиотеки из файла зависимостей:  
*uv pip install -r requirements.txt*
8. Для загрузки аудиокниг требуется установленный в системе FFmpeg (https://www.ffmpeg.org/download.html)    
Для Windows 10/11 удобно его установить командой в PowerShell: *winget install ffmpeg*  

## Запуск скрипта:
1. Активируйте окружение в Windows:  
В PowerShell: *.venv\Scripts\Activate.ps1*  
В CMD: *.venv\Scripts\activate.bat*
2. Запустите скрипт:   
*python YaBooks_downloader.py [ПАРАМЕТРЫ] [ССЫЛКА]*  
__Параметры (необязательные):__  
  *--max_bitrate*&ensp;&ensp;&ensp;Загрузка аудиокниг в максимальном качестве  
  *--min_bitrate*&ensp;&ensp;&ensp;Загрузка аудиокниг в минимальном качестве  
__Ссылка может быть на:__  
  книгу&ensp;&ensp;&ensp;&ensp;&ensp;&ensp;&ensp; - https://books.yandex.ru/books/UUID  
  аудиокнигу&ensp;&ensp;&ensp; - https://books.yandex.ru/audiobooks/UUID  
  комикс&ensp;&ensp;&ensp;&ensp;&ensp;&ensp; - https://books.yandex.ru/comicbooks/UUID  
  серию&ensp;&ensp;&ensp;&ensp;&ensp;&ensp; - https://books.yandex.ru/series/UUID  
  автора&ensp;&ensp;&ensp;&ensp;&ensp;&ensp; - https://books.yandex.ru/authors/UUID  
__Примеры:__

  *python YaBooks_downloader.py --min_bitrate https://books.yandex.ru/audiobooks/AbCd1234*  
  *python YaBooks_downloader.py (интерактивный режим)*  

## Поиск книг (интерактивный режим)
Запустите скрипт без аргументов (*python YaBooks_downloader.py*) и введите название книги или имя автора — откроется список найденного (книги, аудиокниги, комиксы, серии, авторы) с указанием формата у каждой строки.
- Введите один или несколько номеров через пробел, чтобы скачать выбранное.
- *+* — показать ещё результаты; *0* или пустой ввод — вернуться к строке ввода.
- После скачивания список остаётся активным — можно выбрать ещё или ввести новый запрос.
- Пустой ввод в строке запроса завершает программу.

Прямую ссылку или UUID по-прежнему можно вставить — тогда скачивание начнётся сразу.

## Авторизация в ваш аккаунт Яндекс
Для доступа к книгам используется токен, для получения которого необходима авторизация  
![Авторизация](https://github.com/kettle017/RU_Bookmate_downloader/assets/37309120/bb3453eb-5d44-4410-b2e1-05193c88333e)

Полученный токен сохраняется в файл **.env** (переменная `YANDEX_BOOKS_TOKEN`) в папке запуска и используется при последующих запусках. При истечении токена выполняется повторная авторизация автоматически. 

## Скачанные книги
Скачанные в процессе работы книги загружаются в подпапку MyBooks папки запуска скрипта (имя подпапки можно изменить в файле /scr/config.py в переменной MYBOOKS_DIR).  
При этом загружаемые книги загружаются в подпапки по имени автора (Фамилия Имя), внутри которых создаются подпапки по сериям, книги без серий загружаются в корневую папку автора.
Аудиокниги загружаются в единый файл с именем аудиокниги и расширением M4B, в которой в метаданных указаны название аудиокниги, автор, чтец, год, а также разметка на главы.

## Веб-интерфейс (FastAPI, Docker)
Помимо консоли есть веб-версия: поиск сверху, ниже результаты карточками с обложками (книги, аудиокниги, комиксы, серии, авторы). Файлы скачиваются **на устройство пользователя** — на сервере не хранятся.

**Авторизация.** Каждый пользователь входит своим токеном Яндекс.Книги (токен владельца не зашит в приложение). На экране входа вставьте токен или ссылку после входа в Яндекс:
1. Нажмите «Как получить токен?» → «войти в Яндекс».
2. После входа в адресной строке появится ссылка с `access_token=…`.
3. Скопируйте ссылку целиком (или сам токен) в поле входа.

Токен хранится только в вашей сессии (зашифрованная HttpOnly-cookie), сервер его не сохраняет.

**Запуск через Docker Compose:**
```
docker compose up -d --build
```
Откройте `http://СЕРВЕР:8000`. Чтобы сессии не сбрасывались при каждом рестарте, задайте `WEB_SECRET_KEY` — раскомментируйте строку в `docker-compose.yml` и экспортируйте переменную (`export WEB_SECRET_KEY="$(openssl rand -base64 32)"`).

**Запуск через docker напрямую:**
```
docker build -t yabooks-web .
docker run -d -p 8000:8000 -e WEB_SECRET_KEY="секрет" -e WEB_COOKIE_SECURE=0 yabooks-web
```

**Переменные окружения:**
- `WEB_SECRET_KEY` — ключ шифрования cookie сессии. Без него сессии сбрасываются при рестарте (задавать не обязательно).
- `WEB_COOKIE_SECURE` — `1` по умолчанию (cookie только по HTTPS). Для доступа по обычному `http` поставьте `0`.
- `WEB_MAX_DOWNLOADS` — сколько файлов собирать одновременно (по умолчанию 2).
- `PORT` — порт внутри контейнера (по умолчанию 8000).

**Важно:**
- FFmpeg для аудиокниг уже включён в образ. Книги (EPUB) и комиксы (CBZ) работают и без него.
- Сборка аудиокниги идёт минутами — браузер покажет спиннер, затем начнётся загрузка. За обратным прокси (nginx и т.п.) увеличьте таймаут (`proxy_read_timeout`) и включите HTTPS (`WEB_COOKIE_SECURE=1`).
- Потребление RAM одним воркером — порядка 80–150 МБ (большие файлы отдаются потоком, в память не загружаются).
